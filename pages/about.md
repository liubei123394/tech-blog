## 这个站是什么

一个技术学习日志。主要记录四类内容：

- **AI 编程** —— 调用大模型 API、写小工具、和 AI 结对写代码时遇到的问题
- **实战项目** —— 从想法到上线的完整过程，包括技术选型和踩过的坑
- **Bug 排查** —— 报错背后的真实原因，以及定位问题的思路
- **工具笔记** —— 环境配置、开发工具、部署流程的备忘录

## 为什么写

学习过程中遇到的问题，如果不写下来，过几个月大概率会再踩一次。

写出来的过程本身也有价值 —— 很多时候以为自己想明白了，一动笔才发现有个环节说不清楚，那说明其实没懂。

分享出来则是因为：我在别人的博客里省下过很多时间，希望这里也能帮到某个人。

## 内容怎么组织的

每篇文章都是一个 Markdown 文件，放在 `posts/` 目录里，用 Git 管理。所以：

- 每篇文章的修改历史都可以追溯
- 站点本身就是这个仓库的产品，源码结构跟文章一起公开
- 文章会同步到公众号，排版用「复制到公众号」按钮一键搬运

## 怎么联系我

- 提建议或指正错误：欢迎在 GitHub 仓库提 Issue
- 公众号：见页脚
- 邮箱：`you@example.com`

> 如果某篇文章帮你解决了问题，不用特意告诉我。但如果发现内容有错，非常希望你能指出 —— 错误的笔记比没有笔记更糟。
